# Hidden-Damage Bench development records (phase 3; living, not frozen)

Generated by `scripts/hdb_report.py` / `scripts/hdb_identifiability.py --analyse` from VM runs. These are development data:
- no registered test;
- the engine and bench changed between runs, as logged in `docs/HAS_SCIENTIST.md`;
- every figure is NO_AI (engine only) unless a file says otherwise.

| File | Content |
|---|---|
| `VS_v1_engine_v1.md` | v1 fixed severity grid, engine v1 (24 instances) |
| `VS_v2_engine_v2.md` | v2 threshold-relative severities, engine v2 (12 old dev bases, 1.0× / 1.3×) |
| `MKV_v1_engine_v1.md` | Mechanism-Knowledge Value conditions, v1 bench and engine |
| `MKV_v2_engine_v2_partial.md` | Mechanism-Knowledge Value conditions, v2 bench and engine (partial: some shards were still running) |
| `IDENTIFIABILITY_v1_grid.md` | Twin-pair separability on the v1 grid (model-based and model-free) |
| `thresholds_olddev.json` | Failure thresholds of the 12 old dev bases (v2 bench definition) |

Raw episode files are in `artifacts/vm/hdb/` (git-ignored; to be archived with checksums before any registration).
