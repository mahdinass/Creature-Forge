# Engineering amendment 2 — stop or probe

Registered before any v2 outcomes, while the fixed v1 worklist still runs.
V1 first base has no eligible extra-probe decision; all three paths coincide.
This reveals hook availability, not evidence that no useful intervention exists.
V1 source/outputs remain immutable and are reported separately.

V2 uniformly uses ALL qualified bases from the original eight frozen attempts,
regardless of their repair/FULL outcomes. No replacements, subgroup choice or
new independent bases. Baseline v1 records/journals are copied byte-exact with
SHA references; first base repeats default policy to verify the optional hook
has not altered original behavior.

At the first post-start diagnosis stopping decision, alternate policies run ONE
legal probe even if the original would stop. Rank the same existing legal
candidates using the existing EIG computation. Raw-EIG chooses maximum raw gain;
random chooses uniformly among ALL scored candidates if original would stop,
otherwise among nonoriginal choices as v1. Probability1/M or1/(M−1) is recorded.
Before ranking, freeze origin state; before the probe, freeze full candidate
panel and choice. Gold fault/FULL information is not a policy input.

Afterward resume original stopping/diagnosis/repair, total maximum six diagnostic
experiments,700plant/2800twin caps and unchanged FULL. Added ranking/probe costs
are charged to the alternative's original caps; they can reduce repair resources.
This tests a complete allocation path, not the isolated causal effect of a probe
with free twin computation. No outcomes from other paths select a submission.

This is a coverage correction to the ENGINEERING pilot, not a changed scientific
advancement gate or evaluation retry. Practical thresholds/primary target in
DI1_PROTOCOL remain unchanged. All v1 and v2 outcomes, including negatives, are
retained; the same bases are clustered once. No powered evaluation is authorized
by this amendment. Feasibility must account for both pilots and remaining bounds.

Maximum additional native window45minutes, existing SA finisher/timer/watchdog;
parallelism at most eight base processes, six workers each. No Token Factory calls.
