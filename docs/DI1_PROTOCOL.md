# DI-1 protocol — engineering pilot registration v1

This freezes the engineering pilot BEFORE its outcomes. It does not register or
authorize an underpowered prospective advancement test. The final powered
G-DI1 registration, if feasible after the pilot, must be separately committed
and pushed before evaluation generation. Pilot bases may never enter it.

## Population and information boundary

`pilot_config.json` freezes eight attempts, indices 0–7, namespace
`di1-pilot-20261025-v1`. Parent nominal designs are the 18 explicitly named
historical fresh DEVELOPMENT bases; outcomes, family labels and prior successes
are not predictor inputs. Parent pool is fixed infrastructure, not fresh robots.
Each new base independently samples one parent and seven unrounded ±3% body
scales using the frozen Python Random string seed. Nominal controller is fixed
to its parent. All exact bodies and full source-file SHA are registered.
New IDs/numeric bodies differ from all parent designs. Their continuously
perturbed physical identity and unique generation namespace distinguish them
from prior generator runs; no sealed record is opened to test a collision.
This defines a narrow local development population, not broad morphology transfer.

No replacements: nominal qualification requires 7/8 walking with no errors on
check seeds, before policy outcomes. Index cycles existing nine DEVELOPMENT
`FAMILY_SPECS`, first variant; use existing six-bisection failure threshold,
1.3 multiplier, legal strength and existing failed-plant qualification. Save all
excluded attempts. Threshold uses existing HDB function/namespace on new IDs;
policy/check/validate/confirm seeds use DI1 campaign. Family is trusted evaluator
metadata only. Opaque policy_view excludes mechanism/severity/check/FULL seeds.

## Intervention policies

Original v5 A1c5: max_alive12, diagnosis6, 700 plant and 2,800 twin caps;
repair800 twin/300 plant, frozen stopmap_dev_v1/tau .75. No Nemotron calls.
Original diagnosis chooses maximum EIG per rollout. At the FIRST eligible
diagnostic choice only, panel paths instead choose:

- Raw EIG: maximum unnormalized EIG, stable original tie order; probability1.
- Random irrelevant-information control: uniform among legal nonoriginal
  choices, deterministic per-base seed; probability1/(M−1). If none, original.

Candidate universe is exactly the legal existing candidate_experiments result
that received EIG before twin exhaustion, not an outcome-selected subset. Full
ranked universe/parameters/sampling probability/state are frozen in the durable
journal BEFORE selected plant observation. No decision if baseline already
confident or no scored candidates; report no opportunity at this hook. Later
steps use original policy and total six-probe limit. All paths share immutable
seeds, optimizer noise and caps. Raw EIG is an interpretable allocation baseline,
not a learned policy or experience mechanism. It may coincide with the original.

Every eligible base first runs uninstrumented original then instrumented
original. Exact scientific record/ledger/FULL equivalence must pass before its
alternatives. All policy decisions retain original outputs. Each alternative
is an independent full policy continuation, not an oracle selection from the
panel. Panel measurement cannot become free deployment information.

## Prospective gate planning (not yet an evaluation registration)

Independent unit is a newly generated base, one damaged instance/base. Primary
target is equal-cap FULL difference of a frozen observable investigation policy
versus original. A useful effect is 10 percentage points. Opportunity prevalence
must be at least15%, with lower95% bound>5% and at least five independent rescue
bases; raw/predictive policy must outperform random control with a positive
base-level95% interval and at least10pp observed gain. Negative transfer target
≤5%, upper95% bound≤10%. No hidden inputs or extra panel outcomes may select the
deployable path. PASS requires every condition, sufficient preplanned power and
complete valid evidence. FAIL requires a complete powered registered evaluation
failing any criterion. Insufficient information/power/budget => NOT EVALUABLE.

Pilot measures per-base differences/discordance, availability and runtime only;
it cannot pass/fail this scientific gate. Assess required N for 80% power at
two-sided5% using conservative pilot discordance uncertainty, not a favorable
point estimate. Show sensitivity to minimum effects and variance assumptions.
Allow25% runtime margin + qualification/generation + already spent task time.
Both original and uninformed control comparisons must be powered; no selection
of a favorable pilot subgroup/policy. If no defensible design fits, stop NE/NO-GO
with complete pilot evidence rather than launch an incomplete main experiment.
