# H3 implementation report — research prototype only

The implementation is justified as a small nested controller-class test, not as a diagnosed cure or speculative learner. Native physical compatibility and recovery benefit remain unverified. V1 factories, controllers, historical experiments and submission materials are unchanged.

## Files and contracts

- `creature_forge/h3_capability.py`: bounded two-gain stance residual; exact zero-output identity; reset/sense forwarding; strict vector/gain validation; exception-safe single-thread plant-factory scope;17/19D walk/seed jobs; duration-weighted budget pool; matched CMA search reusing the existing kernel and evaluation hooks.
- `scripts/h3_run.py`: non-physics plan creation; explicit-approval-only native gate, qualification and per-case execution; complete policy freezing before verification; rich diagnostic logger; exclusive canonical unit directories, fsynced reservation journal and completed-unit manifests. Worker errors abort without budget reset; prerequisites bind plan, phase and campaign paths. It does not contain Cloud lifecycle, Token Factory or automatic follow-on calls.
- `scripts/h3_analyze.py`: saved-row independent FULL replay,12-lineage stratified bootstrap, strict completeness/seed checks, healthy/harm/persistent-rescue gates, diagnostic clipping/activity checks and explicit pilot-only interpretation.
- `scripts/h3_saved_audit.py`: stdlib-only existing-development evidence recount with hashes and no simulator/model/training calls. Explicit prior-root option accesses existing EM1/DI1 raw records without copying them into this branch.
- `tests/test_h3.py`: non-physics contracts, synthetic search dispatch and analysis-gate fixtures. Fabricated unit-test responses are confined to tests, not reported as research evidence. MuJoCo `mj_step` and `mj_forward` are patched to raise during these tests.
- `experiments/causal_engineer/dev/h3/plan.json`: frozen fresh bodies/seeds, arena variation, budgets and complete package/runner/analysis/protocol source pins. `saved_audit.json` is the preserved completed prior-evidence analysis; final validation and SHA receipts accompany them. No H3 physical outcomes.
- Seven `docs/H3_*.md` documents, project-state/memory updates and `.gitattributes` rules preserve exact new research artifacts.

## Limitations before execution

The plant bridge temporarily replaces a module factory in a dedicated worker process. It refuses Python thread concurrency/nesting and always restores the factory; this is research infrastructure, not a production registry extension. Unit tests validate routing/lifetime including spawned local processes. They cannot establish native physical trajectory equality, actual rollout/throughput behavior on the Cloud environment or19D end-to-end verified recovery. The registered T1 native gate is mandatory.

The prototype has no capability recognizer or learned family selector; it adapts two additional gains by conventional physical search. Its runner is prepared, not physically executed. Proposed candidate batches/seeds and returned aggregate training records are journaled around each dispatch; exceptions preserve a failure receipt and reserved budget. A killed pending batch is not imputed as success/failure. Qualification yield, useful residual authority after clipping, search adequacy, statistical power and deadline fit are uncertain. A hard Cloud API timer and external watchdog must be configured through existing operations tools after fresh approval; a Python dispatch guard is not a billing shutdown mechanism. The receipt's human-message reference documents authorization; it does not independently authenticate a human.

No full repository discovery was launched locally during this preparation. The earlier pause-checkpoint push unintentionally triggered the existing GitHub physics-test workflow; its completed failures and two corrected H3 test-isolation assumptions are explicitly recorded in `docs/memory/INCIDENTS.md` and the validation record. Current publication skips CI rather than triggering it again. CI unit trajectories are not H3 experimental results. The result is a locally tested research prototype with explicit native physical gates pending, not validated functionality or an achieved recovery improvement.
